# RecuPro – Installation
1. Hébergez ce dossier sur une adresse https gratuite (GitHub Pages : nouveau dépôt → téléversez les fichiers → Settings → Pages).
2. Ouvrez l'adresse dans Edge/Chrome (Windows 11) ou Chrome (Android).
3. Cliquez « Installer l'app » (ou menu ⋮ → Installer / Ajouter à l'écran d'accueil).
4. Réglages : entrez une clé API OpenAI ou Gemini, et (pour Gmail) un ID client OAuth Google avec l'adresse de l'app comme origine autorisée.
Test rapide sur PC : `python -m http.server 8000` dans ce dossier, puis http://localhost:8000
